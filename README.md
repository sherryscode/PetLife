## 📖 简介

PetLife 是一个基于微服务架构的宠物生活管理系统，为宠物主人、宠物店商户和系统管理员提供一站式的宠物管理解决方案。系统涵盖宠物健康管理、商城购物、预约服务、社区互动等核心功能。

## 🚀 快速开始

### 环境要求

- JDK 18+
- Node.js 18+
- MySQL 8.0+
- Redis 7.0+
- Nacos 2.2+
- Maven 3.8+

### 1. 克隆项目

```bash
git clone https://github.com/your-username/PetLife.git
cd PetLife
```

### 2. 数据库配置

```sql
-- 创建数据库
CREATE DATABASE petlife DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 导入数据表结构
USE petlife;
-- 执行数据库初始化脚本（如有）
```

### 3. 启动中间件

```bash
# 启动 Nacos
./nacos/bin/startup.sh -m standalone

# 启动 Redis
./redis-server
```

### 4. 启动后端服务

```bash
cd PetBackend

# 编译项目
mvn clean package -DskipTests

# 按顺序启动服务：
# 1. 网关服务（端口 8080）
java -jar petlife-gateway/target/petlife-gateway.jar

# 2. 认证服务（端口 8081）
java -jar petlife-auth/target/petlife-auth.jar

# 3. 商城服务（端口 8082）
java -jar petlife-mall/target/petlife-mall.jar

# 4. 订单服务（端口 8083）
java -jar petlife-order/target/petlife-order.jar

# 5. 健康服务（端口 8084）
java -jar petlife-health/target/petlife-health.jar

# 6. 社区服务（端口 8085）
java -jar petlife-social/target/petlife-social.jar

# 7. 消息服务（端口 8086）
java -jar petlife-message/target/petlife-message.jar
```

### 5. 启动前端应用

```bash
# 管理员后台
cd frontend/petlife-admin
npm install
npm run dev

# 商户后台
cd frontend/petlife-merchant
npm install
npm run dev

# 用户前端
cd frontend/petlife-user
npm install
npm run dev
```

### JWT 认证流程

```
1. 用户登录 → 验证密码 → 生成 JWT Token
2. 前端保存 Token 到 localStorage
3. 后续请求通过 Axios 拦截器自动携带 Authorization 头
4. 网关过滤器验证 Token 有效性
5. 验证通过后提取 userId 和 role 传递给后端服务
```

### AOP 操作日志

```java
@Aspect
@Component
public class OperationLogAspect {
    @Around("@annotation(OperationLog)")
    public Object around(ProceedingJoinPoint joinPoint) throws Throwable {
        // 记录开始时间
        long startTime = System.currentTimeMillis();
        
        // 执行目标方法
        Object result = joinPoint.proceed();
        
        // 记录执行时间和结果
        long executionTime = System.currentTimeMillis() - startTime;
        
        // 保存日志到数据库
        SysLog sysLog = new SysLog();
        sysLog.setExecutionTime(executionTime);
        sysLogService.save(sysLog);
        
        return result;
    }
}
```

### 商品审核流程

```
创建商品(auditStatus=0) → 审核通过(auditStatus=1) → 上架销售(status=1)
                              ↓
                      审核拒绝(auditStatus=2) → 商户修改后重新提交
```

### 订单状态流转

```
商城订单: 待付款(0) → 待发货(1) → 待收货(2) → 已完成(3)
预约订单: 待接单(0) → 已接单(1) → 服务中(2) → 已完成(3)
```
